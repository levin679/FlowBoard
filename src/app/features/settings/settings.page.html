FlowBoard 1.0

Учебный production-like проект для портфолио frontend-разработчика. Реализован на Angular со standalone-компонентами, Signals, lazy routes, reactive forms и локальным репозиторием данных.

Angular 21 LTSTypeScriptSignalsRxJSSCSSVitest

Что рассказать на собеседовании

  1. Почему состояние хранится в сервисе на Signals.
  2. Как computed-значения исключают ручную синхронизацию метрик.
  3. Как реализованы optimistic UI и localStorage persistence.
  4. Как устроены lazy-loaded маршруты и standalone-компоненты.
  5. Какие части заменить REST API и авторизацией в production.
