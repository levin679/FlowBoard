# Описание для портфолио

**FlowBoard — SPA для управления задачами продуктовой команды.**

Я реализовал канбан-доску, фильтрацию и создание задач, дашборд команды и аналитические представления. Состояние построено на Angular Signals, производные метрики — на `computed`, сохранение демо-данных — через абстракцию над localStorage. Страницы загружаются лениво, формы используют Reactive Forms и строгую типизацию TypeScript.

**Практическая ценность:** приложение можно использовать как прототип внутреннего трекера небольшой команды. Следующий production-шаг — подключение REST API, авторизации и real-time обновлений.

**Что демонстрирует:** Angular, TypeScript, Signals, RxJS, Router, Reactive Forms, SCSS, адаптивность, accessibility basics, unit testing.
